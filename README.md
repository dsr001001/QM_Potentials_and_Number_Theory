# Potentials, Primes and Prediction

A textbook that takes a reader with first-year university physics to a full, line-by-line understanding of the paper

> D. Soni, *Fitted potentials on the Wu–Sprung background memorize the Riemann zeros while the explicit formula predicts them* (revision R1, 2026), code and data: [doi:10.5281/zenodo.24035819](https://doi.org/10.5281/zenodo.24035819)

The paper serves as a running case study: every chapter teaches its subject in general and then connects it to the paper. Part VI reads the paper section by section.

**Status:** in progress.

## How the book is made

Directed by Dharmaj Soni. Chapters are drafted by Claude Opus 5.5 and reviewed by Claude Fable 5.2 (Anthropic) against a written specification, [`bible/BIBLE.md`](bible/BIBLE.md). Every number in a worked example is recomputed by a verification script (`tex/checks/`), and every figure is generated by a script (`tex/figs/scripts/`).

## Layout

| Path | Contents |
|---|---|
| `bible/BIBLE.md` | the specification every chapter follows |
| `tex/` | LaTeX sources: `book.tex`, `preamble.tex`, `chapters/`, `figs/`, `checks/`, `refs.bib` |
| `code/qmnt/` | companion Python library: zeta zeros, explicit formula, Wu–Sprung potential, finite-difference solver, the paper's fit |
| `scripts/` | the drafting pipeline (API calls, cost ledger), figure and check runners |
| `ledger/costs.csv` | cost of every API call |
| `work/` | reviewer issue lists and revision records |

## Build

```
pip install numpy scipy matplotlib mpmath
python scripts/make_main.py
python scripts/run_figs.py
cd tex && latexmk -pdf book.tex
```
