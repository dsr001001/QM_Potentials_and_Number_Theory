# Potentials, Primes and Prediction

A textbook that takes a reader with first-year university physics to a full, line-by-line understanding of the paper

> D. Soni, *Fitted potentials on the Wu–Sprung background memorize the Riemann zeros while the explicit formula predicts them* (revision R1, 2026), code and data: [doi:10.5281/zenodo.24035819](https://doi.org/10.5281/zenodo.24035819)

The paper serves as a running case study: every chapter teaches its subject in general and then connects it to the paper. Part VI reads the paper section by section.

**Status:** complete first edition draft (12 November 2026): 32 chapters in six parts plus four appendices, about 1,040 pages, 335 worked Sample Problems, 886 end-of-chapter problems with answers to selected ones, 204 figures. A compiled copy is in [`book-draft.pdf`](book-draft.pdf).

Not yet done: a line-by-line read by a human expert. Treat the text as a careful draft, not a refereed textbook.

## How the book is made

Directed by Dharmaj Soni. Chapters are drafted by Claude Opus 5.5 and reviewed by Claude Fable 5.2 (Anthropic) against a written specification, [`bible/BIBLE.md`](bible/BIBLE.md). Every number in a worked example is recomputed by a verification script (`tex/checks/`), and every figure is generated by a script (`tex/figs/scripts/`).

## Verification record

- Every number in a worked example or answer is recomputed by `tex/checks/<chapter>.py` (6,909 assertions; all pass).
- `qmnt` reproduces the paper's anchors: the oracle rows of Table V (0.198/+0.66 for one prime, 0.043/+0.99 for 25 primes on zeros 401–500), the nulls 0.2631 and 0.2438, the box half-widths 44.883 and 59.957, and the principal operator fit (cosine, M = 400, fit 1–400: in-sample 0.1370, held-out 0.3682, corr −0.0708 against the paper's 0.1370 / 0.3685 / −0.0709).
- Review: every chapter was critiqued by Claude Sonnet 5.5 and revised by Claude Opus 5.5 (465 patches); 16 chapters (the introduction, WKB, zeta, counting zeros, explicit formula, perturbation theory, non-Hermitian, Hilbert–Pólya, Wu–Sprung, fitting, generalization and all of Part VI) received a second review by Claude Fable 5.2 and a second revision (811 patches). Issue lists and revision notes are in `work/`.
- API cost of the whole build: $70.72 (`ledger/costs.csv`).

## Layout

| Path | Contents |
|---|---|
| `bible/BIBLE.md` | the specification every chapter follows |
| `tex/` | LaTeX sources: `book.tex`, `preamble.tex`, `chapters/`, `figs/`, `checks/`, `refs.bib` |
| `code/qmnt/` | companion Python library: zeta zeros, explicit formula, Wu–Sprung potential, finite-difference solver, the paper's fit |
| `scripts/` | the drafting pipeline (API calls, cost ledger), figure and check runners |
| `ledger/costs.csv` | cost of every API call |
| `work/` | reviewer issue lists and revision records |
